# kd-share

河口電機株式会社の共有用ページ置き場です。

- ここに置くHTMLは、すべて StatiCrypt でパスワード保護（AES-256で暗号化）したものです。
- **暗号化する前の元ファイルは置かないでください。** このリポジトリは公開されています。
- `.staticrypt.json` は暗号化の設定（ソルト）です。パスワードは含みません。
- ファイル名は公開されるため、客先名や工事名を入れないでください。
